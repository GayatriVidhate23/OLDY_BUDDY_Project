# Oldy Buddy Frontend

React Native & Expo TypeScript app for Oldy Buddy.

## Features
- Minimal Expo Router navigation
- Auth Screens (Login & Register)
- Dashboard (Home)
- Reminders & Activity Tracker
- AI Assistant Conversation Interface
- One-touch Emergency SOS Trigger
- Elder Profile & Medical Notes
- Family & Caregiver Contacts

## Quick Start
```bash
npm install
npm start
```
